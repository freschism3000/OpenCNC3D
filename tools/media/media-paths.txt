# The movies and the music: the paths no package carries, Red Alert's included.
#
# One path per line, relative to the package root and anchored there by its leading "/",
# which is the form rsync's --exclude-from reads. A trailing "/" is a whole folder. "#"
# starts a comment. Every reader also takes a line written without the leading "/", so the
# two forms mean the same. Paths are literal: rsync, find and a regular expression do not
# agree on what a wildcard matches, so the list holds none.
#
# The readers:
#   tools/mac/make-package-mac.sh and tools/win/make-build-win.sh leave these out of the
#     copy, and refuse a package in which any of them is present however it got there;
#   tools/ra3d/stage-runtime.py, which stages the Red Alert module for both packagers,
#     leaves out the lines under /ra3d/;
#   tools/release.sh refuses a staged folder or a zip that holds one;
#   tools/launcher/data-id.sh leaves them out of the data fingerprint.
