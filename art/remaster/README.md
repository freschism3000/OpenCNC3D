# Remaster lab inputs

The committed inputs of the remaster recipe (`tools/art/remaster`): per building, the
design brief, the identity references, the concept and paintover images, and a sheet of the finished state to compare a rebuild
against. `style/` holds the art-style references.

This folder is kept out of the public source snapshot: it carries third-party reference
art and generated images. Only this README is published.
